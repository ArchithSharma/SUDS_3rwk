Trend arrows

Point color = percentile of the value within the contaminant (all dates). Circles are measured values; diamonds are '<X' values, replaced by the expected value (importance sampling) of the smoothed distribution of measured values below X. Each month shows the reporting period covering it; the most extreme record per facility is used. Arrows start at the facility: red leans up-right = increase, blue leans up-left = decrease; length scales with size of change (none if within ±10%).
For pH, percentile and arrows are based on distance from 7 (|pH - 7|), not the pH value itself.

Records without data (NODI codes)

What do these codes mean? (Click me!)

Where results are not available, a NO Data Indicator (NODI) Code instead of a numerical value is entered into EDMR system. E and FF NODI codes are red flags:

  1. E – Analysis Not Conducted/No Sample. All samples or results are not available due to analytical equipment failure, because a sample collection was overlooked, or samples could not be collected for the parameter during the reporting period. Use of this NODI code results in a violation.
  2. FF – Other (See Comments). No Data, not covered by NODI codes “E” or “GG.” Use only in extenuating circumstances where the reason for the absence of data is not covered by NODI codes “E” or “GG.” Use of this NODI code also results in a violation.
  3. GG – Conditional Monitoring – Not Required. If the permit requires sample collection and analysis only under certain conditions and those conditions were not met during the monitoring period. This includes non-representative outfalls. Use of this NODI code does not result in a violation.
